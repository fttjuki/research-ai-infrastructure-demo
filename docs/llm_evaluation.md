# Checking AI labels against human labels

The file `data/llm_evaluation/synthetic_labels.csv` contains short fictional answers and two labels for each one:

- `human_label`: the made-up human reference label for the example.
- `model_label`: a **simulated** model output entered to test the metric code. It was not generated by calling OpenAI.

The label choices are `trust`, `price`, `habit`, and `other`.

## What the report means

- **Agreement** is the share of rows where the two labels match.
- **Confusion matrix** shows which labels match and where they differ. Rows are the reference (human) labels; columns are the simulated model labels.
- **Cohen's kappa** adjusts the observed agreement for the agreement that could occur by chance, based on the label frequencies in this sample.
- **Precision and recall** are shown for each label to make it easier to see which categories are being mixed up.

The checked-in toy example has 20 rows. Its scores only prove that the calculation code runs; they do not establish that an AI model is accurate. For a real evaluation, create a carefully sampled, independently human-coded reference set, agree on a coding guide, double-code a subset, resolve disagreements, and report uncertainty and class frequencies. A single kappa threshold is not a universal pass/fail rule.
